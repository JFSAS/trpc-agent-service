平台权限与租户权限是两层不同的权限。平台管理员不自动拥有每个租户的业务操作权限。

登录与进入控制台

主页、文档中心和教程公开可读。点击进入控制台后，系统恢复当前浏览器会话：未登录进入登录页，需要首次改密则进入改密页，平台管理员进入管理总览，普通租户用户进入租户选择。

浏览器会话相互独立。在 Zen 中登录不会自动让另一个浏览器同时登录。首次修改密码后，应使用新密码，而不是继续使用初始临时密码。

三种角色

角色 主要职责
Platform Operator 创建平台用户、管理 Operator、开通租户并指定首位 OWNER
Tenant OWNER 管理本租户资源、凭据、部署发布、渠道与成员
Tenant MEMBER 查看资源，准备和发布 Agent、编辑非密钥运行配置、准备和校验部署

涉及凭据、部署发布或渠道写入时，确认自己拥有当前租户的 OWNER 身份。

管理页面入口

  • 平台总览：管理员操作入口，不是运行监控总览。
  • 平台用户：创建用户并设置初始密码；新用户首次登录按要求修改密码。
  • 平台管理员：授权或撤销已有账号的 Operator 身份。
  • 平台租户：开通租户，指定首位 OWNER。
  • 选择租户：只展示当前账号可以进入的租户。
  • 成员管理：OWNER 搜索已有平台账号并添加为成员，或移除普通成员。

添加租户成员不会替代创建平台账号。新同事需要先拥有平台账号，再获得租户成员资格。

入口加载与权限问题

  • 主页和文档不等待 Control API 会话恢复。
  • 控制台入口等待超过 10 秒会显示超时和重试；先确认服务可访问。
  • 用户名或密码错误时，核对当前有效密码，不要不断创建新账号。
  • 看不到租户时，检查成员资格。
  • 页面只读或操作被拒绝时，检查当前租户角色，而不只看平台管理员身份。
